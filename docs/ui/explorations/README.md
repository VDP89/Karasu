# UI explorations — archived prior directions

This folder holds visual / runtime explorations that informed
the current UI direction but are not the path being built.
Kept on the repo for credit, traceability, and future
reference; not actively followed by any UI-N chunk.

## Contents

```text
karasu-win95-runtime-mockup.md
  Win95-styled runtime mockup, drafted on the parallel
  branch feat/ui-1-runtime during the early UI exploration.
  Archived per UI-0 design brief (see
  docs/ui/ui-0-design-brief.md §3 decision D). The current
  visual direction is dark editorial monochrome; the Win95
  retro look was a polarising choice and the operator
  elected the editorial path.

  The mockup remains a useful reference for the per-state
  layout intuitions (header / canvas / drawer) even though
  the visual chrome will not be reused.
```

## Adding new explorations

When a future direction is explored but not chosen:

1. Land the doc on a focused PR.
2. After audit / decision, move it to this folder with a
   one-paragraph entry above explaining what was tried, why
   it was archived, and what (if anything) survived into
   the active direction.
3. Do NOT delete archived explorations. Decision archaeology
   is the point.
