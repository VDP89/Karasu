Typography

Inter Display + JetBrains Mono, both self-hosted woff2 (SIL OFL 1.1). Scale 12–44 px, ratio 1.4. Display tracks tight at -0.01em for ≥20px hierarchy.

--fs-44 Karasu watches the bus
--fs-28 Editorial calm at every layer
--fs-20 UI labels & section headers
--fs-16 Body text. The watchtower's first job is to present the event stream with editorial calm; the second is to give the crow a stage.
--fs-14 Dense rows, compact UI body.
--fs-12 Metadata, timestamps, micro labels.

Focus ring

Two-step inset/outset against any surface. Tab into the controls below to see the ring read. Lint forbids bare outline:none.
